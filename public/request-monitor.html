This backend instance only. Counters start at process startup; recent events are kept in bounded memory. No monitoring database writes or polling. These counts are operations, not billing measurements.

Coverage and privacy

HTTP: completed requests. Database: Knex and native PostgreSQL queries. Cloudflare: server-side R2 SDK commands, including internal retries as one logical call. External: outbound Web Push calls. Durations measure command completion; R2 read timing may exclude streaming the full response.

Direct browser-to-R2 uploads, Cloudflare edge traffic, other Render instances and services outside this backend are not captured. WebSocket delivery is verified separately on Integration Health. Request bodies, SQL values, URL parameters, credentials and customer identifiers are hidden.
